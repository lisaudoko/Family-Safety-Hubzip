## Completed Major Systems

- **Auth**: parent register/login (bcrypt + UUID Bearer sessions, 90-day TTL at issuance, enforced at request time by `requireAuth` since 2026-07-10), child PIN login via family code, forgot/reset password, offline `local_` accounts with background server sync. **Email verification** (implemented 2026-07-11, product owner decision 2026-07-10): registration now issues a hashed 6-digit code (`email_verification_codes`, 15-min TTL, same shape as password-reset codes) and emails it via the existing email mechanism (`sendEmailVerificationEmail` in `src/lib/email.ts`, nodemailer if `SMTP_HOST` is set, else logged — mirrors `sendPasswordResetEmail`). `POST /api/auth/verify-email` (`{ code }`) marks `profiles.email_verified = true` and invalidates the code; `POST /api/auth/resend-verification` reissues one, rate-limited 5/hr per user (mirrors `notifications.ts`'s digest limiter). Both audited via `logAuditEvent` (`email_verification_requested`/`email_verification_completed`). **Verification is informational only — no endpoint or feature is gated on `email_verified` today**; this was an explicit product-owner-silent default (lowest-risk choice), flagged as an open question for future tightening. Mobile: `emailVerified` surfaced on `ApiUser`/`AuthContext.User`, a banner + "Enter code"/"Resend code" modal on the parent Profile tab (`app/(tabs)/profile.tsx`) when unverified; local-only offline accounts default to `emailVerified: true` (no server concept to gate on).

Content lives in DB (`courses`/`lessons`/`quizzes`/`quiz_questions`/`badges`/`weekly_tips` tables) served via `/api/curriculum`; mobile also has static seed in `data/seed.ts`. Parent-facing progress: `GET /api/dashboard/children/:childId/progress` (added 2026-07-11) surfaces a child's `user_progress` (course completion %, earned badges, assessment score) to their parent, family-scoped; `apiGetChildProgress()`/`useChildProgress` exist on mobile but aren't wired into a screen yet.

- **Family**: family CRUD, children profiles (age bands), family technology agreement builder, family code for child login.
